# BLURT — clear Frutiger Aero

Production: https://blurt-eight.vercel.app

The Garden renderer, model and Three.js dependency are removed. The interface uses a sky-and-water scene, prominent clear glass, glossy pink controls, DynaPuff and Nunito, twelve interactive thin-film bubbles and a spring-driven watery pointer. Button hit areas remain stable while their contents sway. Native page transitions and reduced-motion support are included.

Licensed GitHub sources are recorded in THIRD_PARTY_NOTICES.md: MakeAero, Frutiger.js, next-view-transitions and the CC0 professional Serene Tones sound pack. Audio includes OGG and MP3 delivery. No new generated graphics are required by this redesign.

Daily Bloom, Petal Party, Free Bloom and Flash Bloom share authoritative server validation. Guess inputs retain focus after submissions. Late spectators cannot submit guesses or bypass their picture history.

## Finished picture library

2,597 newly audited licensed photographs provide 2,231 shared-stack pictures and 366 reserved daily pictures. The database calendar contains 366 distinct days from 2026-11-16 through 2027-11-16 inclusive, preserving the current launch daily. Ten legacy photos remain available for historical runs.

All 15,582 new prepared WebP objects are private. Source hashes, decoded pixel hashes, canonical answers and first-stage hashes are unique. Every source has explicit reuse licensing and attribution. The no-repeat allocator records guests across solo modes, parties and spectating; exhaustion is explicit rather than recycling images. The temporary content importer is closed with HTTP 410.

The final software-rendered cloud-browser pointer stress run measured 29.3 ms average and 83.4 ms p95 frame intervals; an earlier isolated run measured 17.3 ms average. The implementation targets 60 fps, but a universal 60 fps minimum is not verified and remains a performance limitation on this test host.
